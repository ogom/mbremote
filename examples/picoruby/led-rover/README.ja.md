# PicoRuby LEDローバー

[English](README.md)

2台のmicro:bitを無線接続し、1台をハンドル型コントローラー、もう1台をLED付きローバーとして使います。
MicroPython版`examples/led-rover`の操作、モーター制御、安全停止、画面表示、NeoPixel演出を参照し、PicoRuby版として実装しています。

## 概要

- micro:bitを傾けて、DCモーターで動くローバーを操縦します。
- 対象人数: 1人
- 使用する機能: LED、A・Bボタン、無線通信、加速度センサー、Pin/PWM、NeoPixel
- 対応機種: micro:bit V2

## 遊び方

1. 2台のmicro:bit V2に同じプログラムを書き込みます。
2. 起動時に`?`が表示されたら、コントローラー側はAボタン、ローバー側はBボタンを押します。
3. コントローラーをLED面が手前、USB端子が上になるよう垂直に持ちます。

| 操作                         | ローバーの動作 |
| ---------------------------- | -------------- |
| Aボタンを押す                | 前進           |
| Bボタンを押す                | 後退           |
| AまたはBを押しながら右へ回す | 右へ曲がる     |
| AまたはBを押しながら左へ回す | 左へ曲がる     |
| 両方を離す、または両方を押す | 停止           |

- 中央から約5°傾けると旋回を始めます。
- 傾きが大きいほど内側モーターの出力が下がり、約40°で外側モーターの20%になります。
- 操作信号を500ms受信できない場合は両モーターを自動停止します。
- 停止時は虹色、前後進と左右旋回時は方向別のブロック演出を表示します。

## 設定

- 無線: グループ23、チャンネル7、出力6
- 前進・後退速度: 70%
- NeoPixel: 70灯、輝度20、フレーム間隔20ms
- 操舵方向が逆の場合は[lib/controller.rb](lib/controller.rb)の`STEERING_DIRECTION`を`-1`にします。

## ローバー側の配線

| 用途                       | micro:bit端子   |
| -------------------------- | --------------- |
| 左モーター IN1 / IN2 / PWM | P8 / P9 / P13   |
| 右モーター IN1 / IN2 / PWM | P14 / P15 / P16 |
| NeoPixelデータ             | P0              |

モーターの回転方向が逆の場合は、[lib/rover.rb](lib/rover.rb)の対応する`Motor.new`へ第4引数`-1`を追加します。

モーターとNeoPixelはmicro:bitから直接給電せず、十分な容量の外部電源を使ってmicro:bitとGNDを共有してください。モータードライバーのSTBYはHighにします。

## 書き込み

```sh
mbremote run examples/picoruby/led-rover --language ruby --board v2 --all --force
```
