# MicroPython examples

[日本語](README.ja.md)

These examples run on the official micro:bit MicroPython firmware. Run commands
from the repository root.

| Example | Description | Boards |
| --- | --- | --- |
| [begin](begin/README.md) | Basic display and NeoPixel program | V1 / V2 |
| [filesystem](filesystem/README.md) | Transfer, inspect, and remove persistent files with `mbremote fs` | V1 / V2 |
| [rps-radio](rps-radio/README.md) | Two-player radio rock-paper-scissors | V1 / V2 |
| [led-rover](led-rover/README.md) | Controller and rover using radio, motors, and NeoPixels | V1 / V2 |
| [magic-circle](magic-circle/README.md) | Motion-recognition magic-circle rock-paper-scissors | V2 |

Each example README describes its requirements and how to run it. Reusable
modules are in [`shared/`](shared/); see each example's README for how it uses
them. See the [examples overview](../README.md) for PicoRuby examples and the
[root README](../../README.md) for the full CLI guide.
