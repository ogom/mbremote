# 通信対戦じゃんけん

[English](README.md)

2台のmicro:bitで遊ぶ無線通信じゃんけんです。両方に同じ[main.py](main.py)を書き込みます。

## 概要

- じゃんけんの手を選んで、2人で同時に対戦します。
- 対象人数: 2人
- 使用する機能: LED、A・Bボタン、無線通信
- 対応機種: micro:bit V1 / V2

## 遊び方

### 準備

1. 2台のmicro:bitに同じプログラムを書き込みます。
2. 2人がそれぞれ1台を持ちます。
3. Aボタンで手を選び、Bボタンで決定します。

### 操作方法

| 操作 | 動作 |
| --- | --- |
| Aボタン | グー（ROCK）→ パー（PAPER）→ チョキ（SCISSORS）を選択 |
| Bボタン | 手を決定して相手へ送信 |
| A+Bボタン | 現在の対戦をリセット |

### ルール

- 両方が手を決定すると勝敗を表示します。
- 😀は勝ち、😢は負け、横線はあいこです。
- 結果の3秒後に次の対戦を開始します。

## 設定

- 初期値は無線グループ42、チャンネル7です。
- 複数の組で遊ぶ場合は、ペアごとに`RADIO_GROUP`を別の値へ変更して、2台へ再度書き込みます。
- 手はACKを受信するまで再送されます。

## 開発

2台をUSB接続し、リポジトリのルートで実行します。

```sh
mbremote run examples/micropython/rps-radio --all
```
