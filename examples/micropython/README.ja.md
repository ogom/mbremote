# MicroPythonサンプル

[English](README.md)

これらのサンプルは公式micro:bit MicroPythonファームウェアで動作します。コマンドはリポジトリのルートで実行します。

| サンプル | 説明 | 対応機種 |
| --- | --- | --- |
| [begin](begin/README.ja.md) | ディスプレイとNeoPixelを使う基本プログラム | V1 / V2 |
| [filesystem](filesystem/README.ja.md) | `mbremote fs`による永続ファイルの転送、表示、削除 | V1 / V2 |
| [rps-radio](rps-radio/README.ja.md) | 2人で遊ぶ無線じゃんけん | V1 / V2 |
| [led-rover](led-rover/README.ja.md) | 無線、モーター、NeoPixelを使うコントローラーとローバー | V1 / V2 |
| [magic-circle](magic-circle/README.ja.md) | 動作認識の魔法陣対戦じゃんけん | V2 |

各サンプルのREADMEに必要な機材と実行方法を記載しています。再利用モジュールは[`shared/`](shared/)にあり、利用方法は各サンプルのREADMEを参照してください。PicoRubyサンプルは[サンプル一覧](../README.ja.md)、CLIの詳細は[ルートREADME](../../README.ja.md)を参照してください。
