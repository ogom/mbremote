# LEDローバー

[English](README.md)

2台のmicro:bitを無線接続し、1台をハンドル型コントローラー、もう1台をLED付きローバーとして使います。

## 概要

- micro:bitを傾けて、DCモーターで動くローバーを操縦します。
- 対象人数: 1人
- 使用する機能: LED、A・Bボタン、無線通信、加速度センサー、NeoPixel
- 対応機種: micro:bit V1 / V2（ローバー側のLEDマトリクス表示はV2のみ）

## 遊び方

### 準備

1. 2台のmicro:bitに同じプログラムを書き込みます。
2. 起動時に`?`が表示されたら、コントローラー側はAボタン、ローバー側はBボタンを押します。
3. コントローラーをLED面が手前、USB端子が上になるよう垂直に持ちます。

### 操作方法

| 操作 | ローバーの動作 |
| --- | --- |
| Aボタンを押す | 前進 |
| Bボタンを押す | 後退 |
| AまたはBを押しながら右へ回す | 右へ曲がる |
| AまたはBを押しながら左へ回す | 左へ曲がる |
| 両方を離す、または両方を押す | 停止 |

### ルール

- ハンドルを中央から約5°傾けると旋回を始めます。
- 傾きが大きいほど内側モーターの出力が下がり、約40°で外側モーターの20%になります。
- ローバーが500ms間、操作信号を受け取れない場合は自動停止します。

## 設定

- 無線はグループ23、チャンネル7を使用します。
- 前進・後退速度は`FORWARD_SPEED`と`BACKWARD_SPEED`で調整できます。
- 操舵は`STEERING_DEAD_ZONE`、`STEERING_FULL_SCALE`、`STEERING_MAX_PERCENT`で調整し、左右が逆の場合は`STEERING_DIRECTION`を`-1`にします。
- LEDの明るさは`LED_BRIGHTNESS`で調整できます。

### 配線

| モーター | 方向入力 | PWM |
| --- | --- | --- |
| A（左） | P8、P9 | P13 |
| B（右） | P14、P15 | P16 |

NeoPixelのデータ入力はP0へ接続します。NeoPixelとモーターはmicro:bitから直接給電せず、十分な容量の外部電源を使ってmicro:bitとGNDを共有してください。STBYは3Vへ接続するか、モータードライバー側でHighへプルアップします。

## 開発

2台をUSB接続し、リポジトリのルートで実行します。

```sh
mbremote run examples/led-rover --all
```
