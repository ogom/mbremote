# 制限事項

- MicroPython のファイルシステムはフラットです。`:FILENAME` を使用し、ディレクトリと `fs mkdir` は利用できません。
- `fs`、`exec`、`reset` には MicroPython ボードとシリアル REPL が必要です。PicoRuby には MicroPython REPL とファイルシステム操作はありません。
- 書き込みはボード上の永続的なファームウェアを置き換えます。再書き込みすると `fs` で転送したファイルは削除されます。
- `run` は永続的なファームウェアをデプロイします。デプロイしたプログラムの完了や失敗は検出しません。
- `reset` は REPL を待ってからソフトリセットを送りますが、再起動したプログラムは待ちません。
- `ports` と明示的な `--port` は、micro:bit と識別できるシリアルデバイスだけを対象にします。

コマンドの仕様は [CLI リファレンス](../packages/mbremote/README.ja.md)を参照してください。
